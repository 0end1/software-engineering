# Software Engineering Skill

软件工程全流程开发技能（CodeBuddy Skill）。将工程化方法应用于软件**开发、运行、维护和管理**，支持根据项目特点**自主选择开发模式**并**自由切换**，目标是在满足用户需求的同时，开发出高质量、低成本、易维护的软件系统。

## 功能特性

- **全流程覆盖**：可行性研究 → 需求分析 → 概要设计 → 详细设计 → 编码实现 → 软件测试 → 软件部署 → 运行与维护
- **开发模式自主选择**：根据需求明确度、项目规模、交付节奏、用户反馈、风险程度自动评估并选择最合适的开发模式
- **模式自由切换**：内置切换矩阵，开发过程中可根据情况变化无缝切换模式
- **规范文档生成**：内置 SRS、设计说明书等标准模板，各阶段产出物符合软件工程规范

## 支持的开发模式

| 模式 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **瀑布模型** | 需求明确、变化少 | 管理简单、文档齐全 | 难应对变化、后期改造成本高 |
| **原型模型** | 需求不明确 | 快速澄清需求 | 原型可能被误当成品 |
| **增量模型** | 需分批交付 | 用户早使用、风险小 | 需要整体架构设计 |
| **螺旋模型** | 大型高风险 | 风险驱动、迭代可控 | 过程复杂、成本高 |
| **敏捷开发** | 需求变化快 | 快速迭代、持续反馈 | 文档少、需用户配合 |

## 安装方式

### 用户级（推荐，所有项目可用）

```bash
# 将 skill 目录复制到用户级技能目录
cp -r software-engineering ~/.codebuddy/skills/
```

### 项目级（跟随仓库，团队共享）

```bash
# 将 skill 目录复制到项目技能目录
cp -r software-engineering .codebuddy/skills/
```

### 通过 zip 安装

1. 打包技能（可在任意 CodeBuddy 中验证）：
   ```bash
   python3 "<skill-creator>/scripts/package_skill.py" ./software-engineering
   ```
2. 将生成的 `software-engineering.zip` 导入 CodeBuddy 技能市场安装。

## 使用方法

加载技能后，只需用自然语言描述你的开发需求，例如：

- "开发一个在线商城系统"
- "为这个项目制定开发计划"
- "编写软件需求规格说明书（SRS）"
- "设计这个系统的架构"
- "编写测试方案"

技能会自动评估项目特点并选择开发模式（默认**敏捷开发**），随后按该模式的节奏执行生命周期各阶段，并生成规范的文档与代码。

### 指定/切换开发模式

直接告知想使用的模式，技能会按对应模式调整工作流节奏：

- "用瀑布模型开发这个系统"
- "先做个原型给用户确认需求"
- "改用螺旋模型，重点做风险分析"
- "切换到敏捷开发，按 Sprint 迭代"

## 软件工程核心思想

1. **规范化开发**：遵循统一流程和标准
2. **团队协作**：多人分工合作完成项目
3. **全过程管理**：覆盖需求、设计、开发、测试、部署和维护
4. **质量保证**：通过评审、测试和持续改进提高软件质量
